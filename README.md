# 마르스 비서실 (모바일)

스마트폰 브라우저에서 단독으로 실행되는 「마르스 비서실」 웹앱입니다.

- 주소: https://lvybb1102-lgtm.github.io/mars-secretary/
- 안드로이드 크롬: 주소를 연 뒤 오른쪽 위 ⋮ → **홈 화면에 추가**(또는 설치) → 앱처럼 실행
- 모든 대화·작업·메모·**지침**은 **각 기기 브라우저의 localStorage**에만 저장됩니다. 서버로 전송되지 않습니다.
- AI 응답을 쓰려면 앱 → 설정(⚙️)에서 본인의 Google AI Studio 키(또는 OpenAI 키)를 넣습니다. 키는 그 기기 브라우저에만 저장되며 이 저장소에는 들어 있지 않습니다.

## 지침(공통 규칙) 기능

- 설정(⚙️) 맨 위 **「📜 비서실 공통 지침」**에서 지침을 직접 입력하거나 `.md`·`.txt` 파일로 불러옵니다.
- 지침은 기기별 localStorage에만 있고 **공개 저장소에는 올라가지 않습니다**(내장 기본 업무 규칙 프리셋만 코드에 들어 있음).
- 활성화된 지침만, 총 24,000자까지 systemInstruction에 들어갑니다. 설정 화면에 글자·토큰·호출당 추가 비용이 표시됩니다.
- JSON 백업/복원에 지침이 함께 담깁니다.

- **📎 첨부**: 사진은 긴 변 1,280px JPEG로 자동 축소해 `inlineData`로 보내고, PDF는 8MB 이하, 문서(.txt .md .csv .json .log .html)는 텍스트로 프롬프트에 붙입니다. 채팅 저장에는 썸네일만 남겨 localStorage를 보호합니다.
- **🎨 이미지 생성**: Nano Banana 계열 모델로 생성·저장(다운로드). 2026-11-27 실측 기준 장당 약 64원(2.1 1K, 생각 토큰 포함)~194원(Pro 1K). **선불 결제된 API 키에서만 동작**합니다.
- 실제 모델·실측 단가·검증 결과는 `downloads/2026-11-27_마르스_비서실_모바일_사용법.md` 10~11장 참고.

수정 후 `main`에 푸시하면 1분 안팎으로 반영됩니다.

## 🧠 OpenAI(지피티) — 2026-11-27 추가

- 설정(⚙️) → **「🧠 OpenAI (지피티 · 전략)」** 에 `sk-...` 키를 붙여넣고 **🔌 연결 테스트** → 저장. 키는 **그 기기 브라우저(localStorage)에만** 저장되고 저장소에는 들어가지 않습니다.
- 모델 6종과 1회 예상 비용을 고를 수 있습니다: **GPT-6 Luna(기본 · 약 0.8원)** · GPT-5 mini(약 2.7원) · GPT-6.1 Terra(약 7.7원) · GPT-6.2 Sol(약 15원) · GPT-4o mini(약 1원 · 2027-01-14 지원종료 예정) · GPT-4.1 mini(약 2.7원). (입력 2,000 + 답변 700토큰 기준 추정, 2026-11-27 OpenAI 가격표)
- `@지피티`는 **전략·분석·비교** 담당. `https://api.openai.com/v1/chat/completions`로 1회 호출하며, **활성 공통 지침을 system**으로, **사진은 `image_url`(base64 data URL)** 로, 문서(.txt .md .csv .json .log .html)는 텍스트로 함께 보냅니다. 사용 토큰은 오늘 비용 합계에 들어갑니다.
- `@all`은 Gemini 4명 **합본 1회** + 지피티 **1회** = 총 2회 호출.
- OpenAI 키가 없을 때: `@지피티`만 지목하면 **"OpenAI API 키가 필요합니다" 안내 후 설정을 엽니다**. `@all`이면 지피티만 **1줄 안내로 건너뛰고** Gemini 4명은 정상으로 답합니다(오류 없음).
- PDF는 ChatGPT API가 직접 읽지 못해 지피티 답변에서는 제외하고 한 줄로 알립니다(사진·문서는 정상).
- OpenAI 호출은 브라우저 → `api.openai.com` 직접 호출이라 키가 폰 밖으로 나가지 않습니다(Google Gemini와 같은 방식).

- 오른쪽 위 **접기 / 펼치기** 버튼으로 카드를 접을 수 있고, 접은 상태는 그 기기에 저장됩니다(대화할 때 화면을 넓게 쓰려면 접어 두세요).
- 이미지는 코드가 아니라 `assets/office-map.jpg` 자산입니다. 서비스 워커가 프리캐시하므로 오프라인에서도 지도가 보입니다.
- `downloads/마르스_비서실_모바일.html`(단일 파일판)에는 같은 이미지가 **base64로 내장**되어 있어, PC에서 `file://`로 열어도 지도가 깨지지 않습니다.
