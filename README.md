# 마르스 비서실 (모바일)

스마트폰 브라우저에서 단독으로 실행되는 「마르스 비서실」 웹앱입니다.

- 주소: https://lvybb1102-lgtm.github.io/mars-secretary/
- 안드로이드 크롬: 주소를 연 뒤 오른쪽 위 ⋮ → **홈 화면에 추가**(또는 설치) → 앱처럼 실행
- 모든 대화·작업·메모·**지침**은 **각 기기 브라우저의 localStorage**에만 저장됩니다. 서버로 전송되지 않습니다.
- AI 응답을 쓰려면 앱 → 설정(⚙️)에서 본인의 Google AI Studio 키를 넣습니다. 키는 그 기기 브라우저에만 저장되며 이 저장소에는 들어 있지 않습니다.

## 지침(공통 규칙) 기능

- 설정(⚙️) 맨 위 **「📜 비서실 공통 지침」**에서 지침을 직접 입력하거나 `.md`·`.txt` 파일로 불러옵니다.
- 지침은 기기별 localStorage에만 있고 **공개 저장소에는 올라가지 않습니다**(내장 기본 업무 규칙 프리셋만 코드에 들어 있음).
- 활성화된 지침만, 총 24,000자까지 systemInstruction에 들어갑니다. 설정 화면에 글자·토큰·호출당 추가 비용이 표시됩니다.
- JSON 백업/복원에 지침이 함께 담깁니다.
